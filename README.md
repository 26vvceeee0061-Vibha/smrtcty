# Quantum Flux — Smart City AI Command Center

A scenario-driven water and electricity resource dashboard for the Chronoforge
Smart City AI track, with a LangChain operations brief and a
PostgreSQL-compatible snapshot ledger.

## Run

```bash
npm install
npm start
```

Open `http://127.0.0.1:4173`.

The app runs locally without Docker or a separately installed database:

- **Snapshots** use embedded PostgreSQL (PGlite) at `.data/pglite` by default.
- **AI briefs** use a deterministic local LangChain chain when no OpenAI key is
  configured. Set `OPENAI_API_KEY` to route the same chain through OpenAI.

Copy `.env.example` to `.env` to configure the server. Shell environment
variables override `.env` values.

## Environment

| Variable | Default | Purpose |
| --- | --- | --- |
| `PORT` | `4173` | HTTP port. |
| `HOST` | `127.0.0.1` | Bind address. |
| `DATABASE_URL` | unset | Real PostgreSQL connection string. When set, PGlite is not used. |
| `PGLITE_DATA_DIR` | `.data/pglite` | Embedded database directory. |
| `OPENAI_API_KEY` | unset | Enables the OpenAI-backed LangChain chain. |
| `OPENAI_MODEL` | `gpt-4o-mini` | Chat model used by the OpenAI chain. |
| `OPENAI_TIMEOUT_MS` | `20000` | Upstream advisory timeout. |
| `ADVISORY_PROVIDER` | `auto` | `auto`, `openai`, or `local`. |

### PostgreSQL

The server applies `db/schema.sql` on startup, so the `resource_snapshots`
table and its index are created automatically. To use a real database:

```bash
docker compose up -d postgres
# PowerShell
$env:DATABASE_URL = "postgres://quantum:quantum@127.0.0.1:5432/quantum_flux"
npm start
```

Without `DATABASE_URL`, the same repository code runs against PGlite. This keeps
local snapshots persistent while allowing deployment against standard
PostgreSQL with the `pg` driver.

## API

All resource numbers are recomputed on the server from
`src/data/scenarios.js` and `src/lib/calculations.js`. Client-supplied demand,
supply, or shortage values are ignored.

| Method | Route | Description |
| --- | --- | --- |
| `GET` | `/api/health` | Service, LangChain provider, database driver, and snapshot count. |
| `POST` | `/api/advisory` | Generate an operations brief for `{ scenarioId, controls }`. |
| `POST` | `/api/snapshots` | Recompute and persist `{ scenarioId, controls, label? }` plus its advisory. |
| `GET` | `/api/snapshots?limit=6` | List recent snapshots (newest first, max 50). |

Example:

```bash
curl -X POST http://127.0.0.1:4173/api/advisory \
  -H "Content-Type: application/json" \
  -d '{"scenarioId":"summer-surge","controls":{"demandPressure":120}}'
```

## UI additions

- **AI Operations Brief** — risk badge, headline, summary, and three prioritized
  actions generated by the LangChain chain. Debounced and refreshed whenever the
  scenario or sliders change; falls back to an offline state if the API is
  unavailable.
- **Scenario Snapshot Ledger** — save the active operating point with an optional
  note, then review recent snapshots with their water/power gaps and advisory
  headline. The footer identifies whether the store is PostgreSQL or PGlite.

The existing cards, alerts, calculations, responsive layout, and visual system
are unchanged apart from these extensions.

## Test

```bash
npm test
npm run test:ui
```

- `npm test` covers the shared calculation model, store, local LangChain chain,
  API validation, authoritative server-side recomputation, snapshot
  persistence, and PGlite reopen durability.
- `npm run test:ui` launches headless Chrome against the real dashboard. It
  checks all resource states, slider updates, the AI brief, snapshot save/list,
  responsive overflow at 320 / 390 / 768 / 1440, console errors, and saves
  screenshots to the OS temp directory. Set `CHROME_PATH` if Chrome is installed
  in a non-standard location.

## Architecture

- `src/data/scenarios.js` — single source of truth for scenario demand and supply.
- `src/lib/calculations.js` — scaling, balances, shortage math, and alert derivation.
- `src/lib/store.js` — one observable state object for scenario and inputs.
- `src/main.js` — DOM rendering, controls, advisory refresh, and ledger actions.
- `src/styles.css` — the Quantum Flux dark command-center design system.
- `server.mjs` — static server, API dispatch, and runtime lifecycle.
- `server/advisory.mjs` — LangChain chains: OpenAI prompt/JSON chain and local
  LCEL fallback.
- `server/database.mjs` — snapshot repository for `pg` and PGlite.
- `server/api.mjs` — JSON validation, authoritative computation, and API routes.
- `server/config.mjs` — environment and `.env` resolution.
- `db/schema.sql` — PostgreSQL snapshot schema.
- `compose.yaml` — optional PostgreSQL 16 service.
